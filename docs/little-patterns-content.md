# Little Patterns: all game content and answers

This reference is generated from learning.js and core.js. It contains all built-in answers and content, with no player data. To change sentences, word pools or emoji clues, edit learning.js; sums and patterns are generated by sumRound and patternRound. Run node tools/build-little-patterns-content.cjs after changing the content.
